# Graphos

사진을 자동으로 인식·정리하고, 자연어로 검색할 수 있는 온디바이스 AI 사진 관리 iOS 앱입니다.
Vision과 Apple Intelligence를 기기 내에서만 사용해 서버로 사진이 전송되지 않습니다.

## 🎯 우리가 착안한 문제

사진 라이브러리가 커질수록 **"그때 그 사진이 어디 있더라"** 를 찾는 일이 점점 어려워집니다.

- 사진에 라벨이나 태그가 없어서, 앨범을 스크롤하며 눈으로 일일이 찾아야 한다
- 파일명·날짜 기반 검색만 가능해서, "바다에서 찍은 사진"처럼 기억나는 느낌으로는 찾을 수 없다
- 모든 사진을 손으로 태깅하기에는 번거롭고, 자동 태깅은 완벽하지 않아 보정이 필요하다
- 클라우드 AI에 사진을 올려서 분석하면 프라이버시가 걱정된다
- 검색 기능이 실제로 얼마나 잘 동작하는지, 어떻게 개선해야 할지 근거가 없다

## 💡 문제를 해결하기 위해 필요한 기능

### 1. 사진 자동 인식 · 라벨링
사람이 직접 태깅하지 않아도, 사진을 찍거나 가져오는 순간 내용을 자동으로 인식해 라벨을 붙여야 합니다.

- `PhotoToLabelService` — Vision 프레임워크로 사진을 분석해 신뢰도 0.6 이상인 상위 10개 라벨을 자동으로 추출하고, 바코드/QR 감지 시 별도 라벨을 함께 붙임

### 2. 자연어 사진 검색
"기억나는 느낌 그대로" 입력해도 원하는 사진을 찾을 수 있어야 합니다.

- `NLPService` — Apple Intelligence 온디바이스 LLM으로 자연어 질의를 라이브러리에 실제 존재하는 라벨 어휘 안에서 포함/제외 조건으로 변환함
- `AppleIntelligenceManager` — 기기·설정 상태에 따른 Apple Intelligence 가용성을 확인하고, 사용할 수 없는 이유별 안내 메시지를 제공함
- `MainViewModel` — 검색어를 받아 NLPService 결과로 라이브러리를 필터링하고, 검색 상태(로딩·결과 없음·검색 불가)를 관리함

### 3. 라벨 수동 보정
자동 라벨링이 놓치거나 잘못 붙인 라벨을 사용자가 직접 고칠 수 있어야 합니다.

- `LabelEditingView` — 사진 한 장의 라벨을 확인하고 직접 추가·삭제할 수 있는 편집 화면
- `AppStorageManager` — 사진별 라벨을 SwiftData에 저장·조회·삭제하고, 존재하지 않는 사진의 라벨(orphan)을 정리함

### 4. 부드러운 탐색 · 전체화면 뷰어
사진이 많아져도 그리드 스크롤과 상세 보기가 끊김 없이 동작해야 합니다.

- `IdleView` — 3열 그리드로 보관함을 보여주고, 스크롤에 반응하는 블러 헤더를 그림
- `PhotoGridCell` — 그리드의 개별 셀 UI와 탭·롱프레스 인터랙션을 담당함
- `PhotoImageLoader` — PHCachingImageManager 기반으로 썸네일·원본 이미지를 로드하고, 스크롤 프리페치와 요청 취소를 관리함
- `PhotoThumbnailView` — 개별 썸네일을 렌더링하고, 로딩·삭제됨 상태를 구분해 표시함
- `PhotoDetailView` / `PhotoDetailPageView` — 스와이프로 넘기는 전체화면 사진 뷰어와 상단 컨트롤을 담당함
- `ZoomableImageView` — 핀치·더블탭 줌을 지원하는 UIScrollView 기반 이미지 뷰

### 5. 온디바이스 저장 · 프라이버시
클라우드 전송 없이, 기기 안에서만 사진과 라벨을 다루고 재사용해야 합니다.

- `LocalStorageManger` — Photos 프레임워크로 전체 사진 라이브러리를 불러오고, iCloud 동기화로 생기는 중복 사진을 제거함
- `PermissionManager` — 사진 라이브러리 접근 권한을 요청하고 승인 여부를 반환함

### 6. 검색 기록 저장 · 리포팅
실제로 어떤 검색어가 쓰이는지 근거를 남겨야 개선 방향을 잡을 수 있습니다.

- `SearchLog` — 검색어와 검색 시각을 담는 SwiftData 엔티티
- `SearchLogManager` — 사용자가 실제로 시도한 검색어와 날짜를 저장하고, 전체 기록을 CSV(UTF-8 BOM, 한글 안전)로 내보냄

### 7. 첫 실행 온보딩
권한 요청부터 최초 라벨링까지, 오래 걸리는 작업의 진행 상황을 보여주고 기다림을 줄여야 합니다.

- `LoadingView` — 권한 요청 → 사진 로드 → 라벨링 단계별 진행 상황을 표시하고, 건너뛰기를 지원함

---

## 🛠 기술 스택

- **UI**: SwiftUI
- **로컬 저장**: SwiftData
- **사진 인식**: Vision (`VNClassifyImageRequest`, `VNDetectBarcodesRequest`)
- **자연어 처리**: Apple Intelligence (`FoundationModels`)
- **사진 접근**: Photos / PhotoKit

모든 AI 처리는 기기 내에서만 이루어지며, 별도의 서버·네트워킹 코드는 사용하지 않습니다.
